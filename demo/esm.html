<form-matching-fields> via esm.sh

This page loads the component class from esm.sh and registers it manually. See the README.

Matching validation is loading. Fields remain editable; native required and email checks still work.

These forms don’t send or store your entries. Without JavaScript, the browser checks required fields and email syntax, but doesn’t compare values. Always verify matching values on the server.

Class-only import

The class import doesn’t register the element. Register it before comparing fields. 

import { FormMatchingFieldsElement } from 'https://esm.sh/@aarongustafson/form-matching-fields@1.0.2/form-matching-fields.js?bundle&target=es2022';
customElements.define('form-matching-fields', FormMatchingFieldsElement);

The loading message above reports readiness or import failure. The fields below keep native behavior while loading.

Password confirmation

<form-matching-fields>
  <label>Password <input type="password" required></label>
  <label>Password again <input type="password" required></label>
</form-matching-fields>

Email verification

<form-matching-fields>
  <label>Email <input type="email" required></label>
  <label>Verify email <input type="email" required></label>
</form-matching-fields>

Custom message

Use validation-message with {label_1} and {label_2} to author or translate mismatch feedback. 

<form-matching-fields validation-message="Please make sure {label_2} matches {label_1}.">
  <label>Email <input type="email" required></label>
  <label>Verify email <input type="email" required></label>
</form-matching-fields>
